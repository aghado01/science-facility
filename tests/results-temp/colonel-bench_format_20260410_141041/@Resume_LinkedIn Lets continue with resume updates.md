# is there a way to do this in markdown ?

Markdown natively doesn't support columns — it's a linear format. But there are a few practical workarounds depending on where the resume will actually be rendered.

## What Actually Works

**HTML tables inside Markdown** — most Markdown renderers (GitHub, Notion, Pandoc) support raw HTML inline. You can fake a two-column layout with a borderless table:

```html
<table>
  <tr>
    <td width="30%" valign="top">
      **CONTACT** azriel.ghadooshahy@gmail.com linkedin.com/in/azrielg
      github.com/aghado01 **EDUCATION** MIT — PhD-ABD, Systems Neuroscience UCLA
      — BS Cybernetics, Math Minor **SKILLS** Python, SQL, PySpark, Azure...
      **PUBLICATIONS** Bichot et al. (2019)...
    </td>
    <td width="70%" valign="top">
      ## PROFESSIONAL EXPERIENCE **2021–2025 | Clarify Health Solutions** - ETL
      pipelines...
    </td>
  </tr>
</table>
```

This renders correctly in GitHub, Pandoc → PDF, and most Markdown previewers. It's the closest you can get without a dedicated tool.

## The Practical Reality

| Approach | Columns | Portable | ATS-Safe |
| :------------------- | :----------- | :-------------------- | :----------- |
| HTML table in .md | ✅ Yes | ⚠️ Renderer-dependent | ❌ No |
| Pure Markdown | ❌ No | ✅ Yes | ✅ Yes |
| Pandoc .md → PDF | ✅ Via LaTeX | ✅ Yes | ❌ No |
| Word .docx (current) | ✅ Yes | ✅ Yes | ⚠️ Sometimes |

**The honest recommendation:** the two-column visual is nice but ATS systems (Workday, Greenhouse, Lever) often mangle columns entirely — they read left-to-right linearly and your sidebar content ends up interleaved with your experience bullets in gibberish order.[^16_1]

Alignment Health uses **Workday** specifically. Workday's ATS parser is notoriously bad with columns. A clean single-column Markdown → PDF via Pandoc, or even a plain Word doc, will parse more reliably than the current columnar `.docx`.[^16_1]

## Suggested Practical Path

Keep the columnar `.docx` as the **human-readable version** for when someone actually reads it. Generate a clean **single-column plain text or simple PDF** as the actual upload to Workday. Two artifacts, one source of truth.
