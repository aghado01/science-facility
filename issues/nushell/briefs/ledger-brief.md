# `ledger` — prose changelog with a JSONL store — brief

**Status:** filed, not started · **Filed:** 2026-08-15 · **Home:** nu module,
`mcp/nushell-mcp/modules/ledger/` (MCP-callable through the nushell MCP; no new
server) · **First customer:** reposnapshot (`reposnapshot-v3/CHANGELOG.md`,
`processors/CHANGELOG.md`, both frozen to `-old` 2026-08-15).

## Problem

A markdown changelog with newest-first sections costs an agent the whole file
to prepend one entry — read to find the header, read again to verify — and at
1000+ lines that is most of a context budget spent on history nobody asked
for. The cut-off bought time; it does not fix the mechanism.

## Shape

**Agents submit prose. The tool owns the bytes.** No agent composes or parses
JSON. The record shape below is the tool's internal business.

```
ledger add <prose> [--scope <s>] [--title <t>] [--files a b c] [--commit <sha>]
ledger latest [n=5] [--scope <s>]           # newest-first, rendered as markdown
ledger render [--scope <s>] [--since <date>] # full markdown view (to stdout / a file)
ledger scopes                                 # scopes present in the store
ledger import <CHANGELOG.md> [--scope <s>]    # seed from an existing markdown changelog
```

- `add` appends **one line** to the store: `{ ts, scope, title, body, files, commit }`.
  `ts` = ISO-8601 UTC, stamped by the tool. `title` defaults to the prose's
  first line/sentence. `body` is the prose verbatim (JSON handles the escaping;
  markdown inside is preserved). `commit` defaults to `git rev-parse --short
  HEAD` when in a repo, else absent. `scope` is a plain string (`rs.core`,
  `processors`, …); the current two-files split becomes one store with a scope
  field.
- **Append physically, present newest-first.** Prepend would rewrite every
  byte ahead of the new line — the same cost moved into the tool plus a
  torn-write window. Physical order is invisible because the tool owns both
  ends; `latest`/`render` read and reverse.
- Store location: `CHANGELOG.jsonl` beside the markdown it replaces, found by
  walking up from cwd (nearest wins); `--ledger <path>` and `$env.LEDGER`
  override. One store per project root, scoped, not one per directory.
- `render` produces the same house style the markdown files use
  (`## <date> — <title>` + body), so a human-facing `CHANGELOG.md` can be
  regenerated on demand rather than maintained by hand.
- `import` parses `## <date> — <title>` sections of an existing markdown
  changelog into entries (date → `ts` at midnight UTC, section text → `body`).
  Best-effort on the frozen `-old` files; exact on the fresh ones.

## Non-goals

- Editing or deleting entries. Corrections are new entries that say so.
- A schema for prose. Body is free text.
- Replacing git history. Commits say *what changed*; the ledger says *why*, in
  the voice the project's changelogs already have.
- A separate MCP server. `ledger add …` runs through `mcp__nushell__evaluate`
  once the module is loaded by `config.nu`.

## Exit gate

`mcp/nushell-mcp/modules/ledger/tests/` (nu, `std assert`):
- `add` → `latest 1` round-trips a body containing quotes, backslashes, and
  newlines byte-for-byte.
- `add` grows the file by exactly one line; earlier bytes untouched (compare
  prefix hash before/after).
- `latest 3` returns newest-first across two scopes with `--scope` filtering.
- `render` of a two-entry store equals a fixture markdown string.
- `import` of the fresh `reposnapshot-v3/CHANGELOG.md` yields the expected
  entry count and titles.
- Module registered in `config.nu`; `nu-modules` lists it.

## Open calls

- Store name/location: `CHANGELOG.jsonl` beside the markdown vs
  `.ledger/changelog.jsonl` — leaning beside, for locality.
- Whether `CHANGELOG.md` is retired outright or kept as a rendered artifact
  (regenerated by `render`, never hand-edited).
- Whether `add` should also refuse when the working tree is dirty and no
  `--commit` is given (forces the *why* to travel with a real *what*), or stay
  permissive.
- Default scope when none is given: none (`scope: null`), or derived from cwd
  relative to the store — leaning none; explicit is cheap.
