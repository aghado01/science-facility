# mdnav v2 — decisions register

One line each, ascending, with the reason and where it came from. This is
the audit trail for the design brief: if a later change contradicts a row
here, either the row is amended with a date or the change is wrong. Sources:
**G** = Gemini note 2026-08-16, **F** = fable-review 2026-07-29, **C** =
codex spec v0.1, **S** = Sol XOR note, **P** = para-agent
addressable-context-stream note, **T** = this thread 2026-08-17, **D** =
doccer README/source.

| # | decision | why | src |
|---|---|---|---|
| D1 | mdnav 2.0 generalizes the substrate; **nothing currently working is discarded** — every verb keeps CLI, output format, anchors, byte-fidelity covenant. | It is a foundation for the mdnav MCP, not a replacement product; goldens make this checkable. | T |
| D2 | A mask is an **index layer**, not a hiding mechanism: kinds are indexed independently so any reader can filter, isolate, count, compose. | Corrects rev-1 framing; enables profiles. | T |
| D3 | **Suppression is a query policy, never a claim property.** No `is_noise`/`is_mask` on claims; "noise vs prose" is a profile. | Doccer `Suppression.cs` verbatim; one fence suppresses headings under one query and is the target under the next. | D, T |
| D4 | The engine discovers **typed constructs as claims**; kind vocabulary is open; overlap and nesting preserved. | Documents contain typed objects; signal/noise is disposition. | T, D |
| D5 | Port from doccer: `SpanSet` (identity-forgetting algebra), claims/`SpanBatch` shape, `PatternRule` collectors with region-scoped execution, prefix parity, nearest-container, `RewritePlan`-shaped piece list. **Doccer is never a runtime dependency.** | Bazooka for a knife-fight; nothing calls .NET. | G, S, T |
| D6 | Not ported: Allen relations, `ClaimPairView`, path selection, facts/saturation, origins, vectors beyond parity, second segmentation policies. | Keep the knife a knife; separate contracts if ever needed. | T |
| D7 | Delimiter geometry is the unifying collector spec: **boundary / toggle / pair**; a spec is data `{pattern, geometry, scope, kind}`; built-ins are shipped specs; callers may pass one. Partitions are validated values. | Idiomatic Markdown constructs are recognizable by their delimiters; masking/isolating/segmenting are one operation with different arguments. | T |
| D8 | HTML blocks by CommonMark **block start/end conditions 1–7**, never open/close tag pairing; type 2 emitted as `html-comment`, not `html-block`. | Unclosed `<div>` in a transcript must not swallow the file; comment and block must not double-claim. | T (+ reviewer note) |
| D9 | `html-tag` (single tag, inner text kept) and `html-block` (whole block) are **two kinds**; "strip tags keep prose" (today's default) is a projection over the first. | Preserves README §Triage policy under the general model. | T |
| D10 | Footnotes (`[^l]`/`[^l]:`) and link reference definitions are **core kinds**, with keyed **relations** (`footnote`, `link-ref`, `anchor`, `contains`) returning pairs + residue. No `citation-ref` kind; no site-specific rule inventories for idiomatic Markdown. | Idiomatic Markdown, not a Perplexity disposition; the ref→def relation is what a preview renders as a click. | T |
| D11 | Nested headings: `# x` inside a region (html-block, blockquote) is a **heading claim with a container**; ids stay ordinal over all heading claims; activation = `level ≤ depth ∧ container chain transparent`; **`--enter <kinds>`** is the third knob (basis / depth / extent / *enter*); default `enter` empty; `outline` names what it does not descend into. | Nested, not flattened, not ignored; anchors do not move; nothing silently omitted. | T, S |
| D12 | Re-entry runs region-specific rules over the region window **in source coordinates**; no derived masters, no OffsetMap, no prefix stripping. | Doccer defers OffsetMap too; coordinates stay one space. | T, D |
| D13 | Generic basis `--by <kind | pattern:<re>>`; boundary bases address `Snnnn`, region bases `Rnnnn`; gaps between regions are units; `--within … --by` re-segments recursively; **first-viable-boundary is the only policy**. | The XOR walk in CLI form; tiling invariant per basis. | S, T |
| D14 | Claims engine is **in-memory first**; `MemoryStore` (server) and `SidecarStore` (one-shot CLI) share schema 3; views never persisted. | A server is a persistent process; sidecars are the CLI's cold cache. | T |
| D15 | **Persistence with rehydration, not accretion:** corpus-scoped `index/` (inventory + one `documents/Dnnn.json` per doc, replaced in place, ids stable across runs and restarts); run-scoped `<stamp>/reads.jsonl` + `run.json`; `runs prune --keep`. Work-dir resolution and the refusal guard unchanged. | N discoveries of one small doc must not leave N indexes; a run *is* provenance and stays stamped. | T |
| D16 | Front-end grammar mirrors `nu-skills`/`nu-modules`: list/read/search/inspect/status with **typed pure-content returns** (bytes, table, record); progressive disclosure; never prose. | Already running in `nushell-mcp`; mdnav maps verb-for-verb. | T |
| D17 | **REPL contract:** every query paged + counted (`{total, rows}`), memoized by `(digest, policy, args)`; `materialize` takes `maxBytes` and returns a **plan** (zero bytes) when over; bytes-or-table never both; previews capped at the engine; anchors are the agent's memory; session handles are plain data. | The caller's context is the scarce resource; `nu --mcp`'s `$history` is the model. | T |
| D18 | Stream framing: **front-declared, typed, addressed regions** — `¶ addr k/N kind basis ~size policy… span= len=`; header grammar is a **shared spec with para-agent** that mdnav conforms to; `--frame comment|pilcrow|none` as a projection over the piece list; `comment` = CLI default (byte-identical to today), `pilcrow` = MCP default; placeholders are addressable zero-`len` regions. | Documents and exchanges become one kind of object in the Primary's stream; declare-before-payload has a causal-attention rationale. | P, T |
| D19 | `len` (emitted UTF-8 bytes) and `span` (source geometry) are **always distinct fields**, both machine-facing; the model-facing magnitude is `k/N` + coarse size. Byte `len` claims **no attention benefit**. | Byte-semantics trap; models do not count bytes; the boundary the model uses is the next sentinel. | T |
| D20 | The framing value proposition is **evaluated behaviorally** (framed vs unframed; address-recall, misattribution, tokens-to-answer) — a server-brief gate, not an assumption. | Attention is not observable from outside; carry the claim honestly. | T |
| D21 | mdnav 2.0 will be **vendored into para-agent** like `nushell-mcp`: engine single-file zero-dep; server embeddable `createMdnavTools({corpus, session, framing})` + thin stdio runner. | Para-agent supplies session/result store; addresses fit transcript rows. | T |
| D22 | **Rewrite the engine from the old file as figure model**: tests + goldens first, presentation/IO ported with intent, README as second figure model. v2 lives in `mcp/mdnav_v2/`; the legacy `skills/doc-dive/mdnav/` is the oracle and is **never edited**; repointing the doc-dive skill at v2 is a separate one-line decision at parity (2026-08-17: amended from "replace in one commit" after the move in `38710e0`). | The brief inverts control flow; retrofit would carry the old seams; a blank page would lose behaviors the brief does not restate. | T |
| D23 | **No parallel sub-agents.** Chip A (M0–M3, parity) → Chip B (M4–M5) → fresh-context review; sequential, worktree-isolated, reports appended to the brief. | One file, hard ordering, golden baseline must precede any change. | T |
| D24 | Fable-review F1–F4 and cosmetics are absorbed here (still open in code as of 2026-08-17), not filed again. | Same bugs, structural fix. | F, T |
| D25 | Cadence thresholds and `GapCadence` alignment are out of scope; report whether the claims refactor makes alignment free. | Not on the critical path. | T |
| D26 | Default MCP budget number is **not** chosen in the brief; the report proposes one from measured reads. | Tune against evidence. | T |
| D27 | Planning artifacts live in `issues/mdnav_v2/planning/` (this register, roadmap, figure-model survey); the brief remains design canon and is amended, not forked. | The brief had grown into canon + roadmap + method; split by role. | T |
