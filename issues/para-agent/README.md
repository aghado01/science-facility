## Para-agent issues layout

**briefs** - briefings for development tasks
**discussions** - chat logs about para-agent
**notes** - freeform scratch notes / user brain dump
**planning** - canon for planned roadmap and sequencing, design decisions ledger, implementation log, codified architecture and design specs
**reports** - reports related the para-agent mcp implementation at a given point in time and design draft artifacts
**specimens** - detailed transcripts of para-agent sessions. do not confuse unrelated subject matter of specimens with evidence they provide about how the para-agent MCP was working at the time
